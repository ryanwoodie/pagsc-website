# Welcome pack source

The nine pages of the PAGSC welcome pack, as designed. Use them as the reference for the site's look (colours, type, spacing, components, the glider drawings and the map of the schedule sheet) and as the origin of most of the copy.

Each `.dc.html` file is one 816 by 1056 px page. The markup between `<x-dc>` and `</x-dc>` is plain HTML with inline styles and can be read directly; the files are not meant to be served as they are.

| File | Page |
| --- | --- |
| `Main.dc.html` | 1. Cover: three steps to start |
| `P2-Schedule.dc.html` | 2. The Flying Schedule, with the map of the sheet |
| `P3-FlyingDay.dc.html` | 3. The morning you fly, and your first day |
| `P4-Costs.dc.html` | 4. Costs and quick answers |
| `Why.dc.html` | 5. Why gliding, with the ladder |
| `P5-Learning.dc.html` | 6. Learning to fly |
| `P6-FastTracks.dc.html` | 7. Youth and cadets, power pilots |
| `Fleet.dc.html` | 8. The fleet, with the three glider outlines |
| `P7-Contacts.dc.html` | 9. Links and contacts |

Images referenced as `/_blob/…` are QR codes; two are included here as PNG files.

Where this pack and `content/club-facts.yaml` disagree, the facts file wins.
